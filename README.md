# Space Arm

Space Arm é um jogo de ação em primeira pessoa onde você controla um braço mecânico no espaço, defendendo-se contra ondas de inimigos.

## Como Jogar

### Controles
- **W**: Mover para frente
- **S**: Mover para trás
- **A**: Mover para esquerda
- **D**: Mover para direita
- **Q**: Subir
- **E**: Descer
- **ESPAÇO**: Atirar

### Objetivo
Eliminar inimigos, acumular pontos e avançar de nível. Cada nível apresenta um tema diferente e inimigos mais desafiadores.

## Recursos
- Sistema de níveis progressivos
- Diferentes temas visuais
- Sistema de upgrade de armas
- Sistema de salvamento de progresso
- Mapa interativo

## Instalação
1. Clone este repositório
2. Abra o arquivo `space_arm.html` em seu navegador

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript

## Créditos
Desenvolvido como um projeto de demonstração de jogos baseados em navegador usando tecnologias web padrão.
